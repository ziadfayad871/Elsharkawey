# Elsharkawy Tech Landing Page

A modern Arabic RTL landing page for **Elsharkawy Tech For Air Conditioning & Refrigeration**.

## Features
- Responsive Arabic RTL design
- Animated hero section
- Services section
- Brands/products section
- Statistics counters
- Project gallery
- Contact cards
- WhatsApp floating button
- Google Maps integration
- Smooth scrolling
- AOS scroll animations

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts
- AOS Animation Library

## Project Purpose
This project was created as a professional landing page for an air conditioning and refrigeration business, presenting services, products, business information, and contact details in a clean and interactive design.
